# 墨尔 markdown editor v1.0.0

## 更新

- 右上角新增查找与替换，支持区分大小写、逐项替换和全部替换。
- 单击正文、代码块或公式时保留渲染效果。双击代码块或公式可进入编辑。
- 悬停标题时显示 H1 至 H6。工具栏随光标更新格式选中状态，工具栏和大纲使用 VS Code 当前主题的交互配色。
- 代码块操作依次为主题、自动换行、复制和删除。正文滚动时，大纲跟随当前位置。
- 撤销和重做会定位到改动处。加粗和斜体直接更新 Markdown 文本。
- 修复网页、本地文件和文档内链接。文内跳转后按 **Esc** 可逐次返回点击前的位置，快捷键可在 VS Code 中修改。

## 安装与验证

下载 `moye-markdown-1.0.0.vsix`，在桌面版 VS Code 的扩展菜单中选择「从 VSIX 安装」。已安装同一扩展标识的用户可直接升级。

需要桌面版 VS Code 1.95.0 或更新版本。已在 Windows VS Code 的三种编辑模式验证文内跳转和 Esc 回退，并通过浏览器回归测试。

本项目在 [Vanessa219/vditor](https://github.com/Vanessa219/vditor) 的 Vditor 4.0.1 源码基础上修改并适配 VS Code，原版权和 MIT 许可随安装包分发。
