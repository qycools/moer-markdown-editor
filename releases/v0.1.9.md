# 墨尔 markdown editor v0.1.9

## 来源声明

本项目是在 [Vanessa219/vditor](https://github.com/Vanessa219/vditor) 开源代码基础上修改、扩展并适配 VS Code 的项目，使用 Vditor 4.0.1 源码。Vditor 采用 MIT 许可，原作者版权与许可声明保留在仓库和安装包中。

## 更新

- 整合 [Emeric53 的 macOS 适配 PR #1](https://github.com/qycools/moer-markdown-editor/pull/1)：Cmd 快捷键、浏览器与 `.app` 检测、家目录路径展开及 macOS 字体。
- 原生撤销/重做同步到 VS Code 文档历史，图片粘贴兼容剪贴板文件条目。
- 补齐完整源码、修改后的 Vditor 源码、依赖锁、类型检查及测试工程，统一使用标准 VSIX 打包。

## 安装与验证

下载 Assets 中的 `moye-markdown-0.1.9.vsix`，在 VS Code 扩展视图的“…”菜单中选择“从 VSIX 安装”。已安装旧版的用户可直接升级。

需要桌面版 VS Code 1.95.0 或更新版本；导出需要本机浏览器。Windows 编辑、保存、撤销重做、主题、公式图表和 PDF/HTML/DOCX 导出完成回归验证。macOS 路径逻辑通过自动化测试，本次尚未完成 macOS 实机验收。

PlantUML 使用联网渲染，远程图片和媒体需要网络。后续更新需下载新版 VSIX 手动安装。
