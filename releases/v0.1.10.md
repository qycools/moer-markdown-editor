# 墨尔 markdown editor v0.1.10

## 更新

- 本地图片加载失败时，可回读文档目录或工作区中的图片。点击图片可调整尺寸、按比例缩放、复制引用和删除。
- Markdown 表格支持通过单元格或边线增删行列、设置列对齐，以及切换列等宽和自适应宽度。
- 工具栏新增思维导图。精简版显示标题层级，详细版加入嵌套列表、任务状态和段落摘录，两种导图均可导出为 SVG 或 Markdown，也可插入正文。
- 正文中的 Markmap 图块支持拖动底边调整高度，双击可恢复默认。高度随文档保存。

## 安装与验证

下载 `moye-markdown-0.1.10.vsix`，在桌面版 VS Code 的扩展菜单中选择「从 VSIX 安装」。已安装同一扩展标识的用户可直接升级。

需要桌面版 VS Code 1.95.0 或更新版本。本版在 Windows 验证了本地图片、表格和思维导图操作，并实测了两种导图文件的导出及保存后重开恢复高度。macOS 尚未完成本版实机验收。

本项目基于 [Vditor 4.0.1](https://github.com/Vanessa219/vditor)，原版权和许可声明随安装包分发。
